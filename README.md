# App1 - Сборник псалмов

Веб-приложение для поиска и чтения псалмов с поддержкой 8 коллекций.

## Функции

- 🔍 Поиск по номеру или названию
- 📖 8 коллекций псалмов (1005+ псалмов)
- ❤️ Система избранного
- 📋 Копирование текста
- 💾 Кэширование (7 дней)

## Коллекции

| Буква | Название | Макс. номер |
|-------|----------|------------|
| п | Песни Юности | 1005 |
| к | Кувшинчик | 89 |
| н | Новые псалмы | 217 |
| г | Горлица | 571 |
| с | Псалмы Сиона | 525 |
| м | Мы поём Господу | 200 |
| юс | Мелодия юных сердец | 850 |
| гх | Голосок хваления | 393 |

## Установка

```bash
npm install
npm start
```

Приложение будет доступно на http://localhost:8080
